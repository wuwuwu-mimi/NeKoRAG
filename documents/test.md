# 核心概念：迭代式 Prompt 开发

1. **首次成功率低但无关紧要**：在构建实际应用时，几乎没有人能第一次就写出完美适配的 Prompt。关键不在于写出完美的 Prompt，而在于**拥有一套能够不断改进 Prompt 的迭代流程**。
2. **类似于机器学习的开发流程**：
* 机器学习流程：想法（Idea） $\rightarrow$ 实现/编写代码（Code） $\rightarrow$ 训练/获取数据（Data） $\rightarrow$ 实验结果（Evaluation） $\rightarrow$ 错误分析（Error Analysis） $\rightarrow$ 修正想法并重复。
* Prompt 开发流程：设定任务想法 $\rightarrow$ 编写遵循“清晰明确”、“给予思考时间”原则的初版 Prompt $\rightarrow$ 运行并查看结果 $\rightarrow$ 分析结果（找出指令不清或思考时间不足的原因） $\rightarrow$ 优化 Prompt $\rightarrow$ 再次测试。

# 核心案例演示：从“产品说明书”生成“营销文案”

文章通过为一把“中世纪风格办公椅”的说明书（包含结构、尺寸、材料、原产国意大利等信息）编写营销文案的案例，展示了三次迭代优化的全过程：

### 迭代 0：初始尝试

* **任务**：直接要求模型根据技术说明书编写一段产品描述。
* **结果**：模型很好地完成了任务，但**文本内容过长**。

### 迭代 1：解决“生成文本太长”的问题

* **修改思路**：在 Prompt 中明确增加长度限制。
* **Prompt 优化**：加入约束条件 `使用最多50个词。`。
* **发现的 LLM 特性**：大语言模型（LLM）由于使用分词器（Tokenizer）而非字符来计数，在遵循极其精确的字数限制时表现一般，但大体能将篇幅控制在合理范围内。

### 迭代 2：解决“文本关注在错误的细节上”的问题

* **修改思路**：改变受众定位。该网站是面向“家具零售商”而非普通消费者，零售商更关心技术细节和材料构造，且需要包含产品 ID。
* **Prompt 优化**：加入背景描述 `该描述面向家具零售商，因此应具有技术性质，并侧重于产品的材料构造。`，并要求 `在描述末尾，包括技术规格中每个7个字符的产品ID。`。
* **结果**：模型的输出变得更具专业性，侧重于材料构造（如改性尼龙、HD36泡沫），并在末尾准确附上了产品 ID。

### 迭代 3：解决“需要特定结构和格式（表格/HTML）”的问题

* **修改思路**：为了能让前端直接使用，要求抽取尺寸信息并组织成 HTML 表格。
* **Prompt 优化**：加入格式和布局指令：
* 将描述放在 `<div>` 元素中。
* 在描述后包含一个两列的 HTML 表格命名为“产品尺寸”，第一列为尺寸名称，第二列只包含英寸测量值。


* **结果**：模型完美地输出了符合网页结构要求的 HTML 源码（包含 `<div>`、`<p>` 和 `<table>` 标签）。

# 文章总结与建议

* **过程胜于结果**：开发成功的 Prompt 往往需要经历上述的迭代过程。
* **高级应用测试**：对于更复杂的应用程序，可以在多个样本上进行迭代 Prompt 开发。当应用走向成熟时，应该在多个样本（数十或数百个）上测试多个 Prompt 的平均性能或最差性能，以确保鲁棒性。
